# Historical design and implementation records

The plans and specs in this directory preserve technical analysis from earlier Minime work.
They are not the active development workflow, do not grant or restrict authorization, and must
not be executed as checklists unless the owner explicitly revives a named document.

Use `CLAUDE.md` for current product/safety guardrails and `docs/DEVELOPMENT.md` for the active
single-owner workflow and completion roadmap. When extracting useful technical requirements from
an old plan, carry only the behavior and risk control into the current task; leave its mandatory
skills, role matrices, approval chains, SHA locks, branch choreography, and repeated gates behind.
